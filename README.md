# AI-chat-knowledge-bot
Чат-бот, которому загружают информацию о компании (документы, таблицы, аудио, видео и т.д.). Бот отвечает на вопросы сотрудников/клиентов на основе загруженных данных.  
Дополнительно:
- Встраивается на сайт через HTML/JS-виджет
- Поддерживает загрузку разных форматов
- Имеет Text-to-Speech (озвучивание ответов)
