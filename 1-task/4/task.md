# Задание №4. Термины, бизнес-правила и сущности предметной области

### Краткое описание предметной области

Разрабатываемая система предназначена для управления корпоративными знаниями и предоставления сотрудникам или клиентам ответов на основе информации организации.

---

## 4.1. Термины предметной области

| Термин | Определение |
|---|---|
| **Организация / Компания** | Владелец корпоративной базы знаний и настроек AI-ассистента. |
| **База знаний** | Совокупность информационных материалов организации, используемых AI-ассистентом для поиска информации и формирования ответов. |
| **Документ** | Информационный материал, загруженный в базу знаний. Это может быть текстовый файл, PDF, DOCX, таблица, аудио или видео. |
| **Индексация** | Процесс подготовки содержимого документа для последующего поиска информации по запросам пользователей. |
| **RAG (Retrieval-Augmented Generation)** | Подход к формированию ответа, при котором перед генерацией система находит подходящую информацию в базе знаний и использует её как контекст для ответа. |
| **Транскрипция** | Текстовое представление речи, полученное из аудио- или видеоматериала. |
| **Диалог** | Последовательность сообщений между пользователем и AI-ассистентом. |
| **Сообщение** | Отдельный вопрос пользователя или ответ AI-ассистента в рамках диалога. |
| **Администратор** | Пользователь, имеющий права на управление базой знаний, документами, пользователями и настройками. |
| **Виджет** | Встраиваемый на сайт компонент, через который пользователь может взаимодействовать с AI-ассистентом. |
| **TTS (Text-to-Speech)** | Преобразование текстового ответа AI-ассистента в речь. |

---

## 4.2. Бизнес-правила и ограничения

1. **Использование базы знаний.**  
   AI-ассистент может использовать для ответа только те материалы, которые были успешно обработаны и добавлены в базу знаний.

2. **Разграничение доступа.**  
   Пользователь может получать информацию только из тех баз знаний и документов, к которым ему предоставлен доступ.

3. **Изоляция данных организаций.**  
   Данные одной организации не должны быть доступны пользователям другой организации.

4. **Обработка документа перед использованием.**  
   Загруженный документ не может участвовать в поиске и формировании ответа до завершения его обработки и индексации.

5. **Поддержка различных типов материалов.**  
   Текстовые документы, таблицы, аудио- и видеоматериалы должны быть приведены к форме, пригодной для использования в базе знаний.

6. **Обработка аудио и видео.**  
   Перед использованием аудио- или видеоматериала содержащаяся в нём речь должна быть преобразована в текстовую транскрипцию.

7. **Удаление документа.**  
   После удаления документа его содержимое не должно использоваться при формировании новых ответов.

8. **Повторная индексация.**  
   При обновлении документа его устаревшие данные должны быть заменены актуальными после повторной обработки.

9. **Недостаток информации.**  
   Если в доступной базе знаний отсутствует достаточная информация для ответа, AI-ассистент не должен придумывать корпоративные факты.

10. **Связь ответа с источниками.**  
    Для сформированного ответа должна сохраняться возможность определить, какие документы или их фрагменты были использованы.

11. **Управление базой знаний.**  
    Добавлять, удалять и повторно обрабатывать документы могут только пользователи, имеющие соответствующие права.

12. **История диалогов.**  
    Сообщения пользователя и ответы AI-ассистента могут сохраняться в рамках диалога для последующего просмотра.

13. **Встраиваемый виджет.**  
    Виджет на внешнем сайте должен использовать настройки и базу знаний той организации, которой он принадлежит.

14. **Озвучивание ответа.**  
    Пользователь может запросить озвучивание ответа. Аудиоверсия должна соответствовать содержанию текстового ответа.

15. **Статус обработки.**  
    Пользователь, имеющий права управления документами, должен иметь возможность определить текущее состояние обработки загруженного материала.

## 4.3. Основные сущности предметной области

| Сущность | Назначение | Примеры основных характеристик |
|---|---|---|
| **Организация (Company)** | Представляет компанию, которой принадлежат база знаний, пользователи и настройки | название, статус, настройки |
| **Пользователь (User)** | Человек, взаимодействующий с системой | имя, email, роль, статус |
| **Роль (Role)** | Определяет права пользователя в системе | название роли, набор разрешений |
| **База знаний (Knowledge Base)** | Объединяет корпоративные информационные материалы | название, организация, статус |
| **Документ (Document)** | Представляет загруженный информационный материал | название, тип, размер, дата загрузки, статус |
| **Транскрипция (Transcript)** | Представляет текст, полученный из аудио или видео | текст, язык, исходный материал |
| **Диалог (Conversation)** | Представляет сеанс общения пользователя с AI-ассистентом | пользователь, дата создания, статус |
| **Сообщение (Message)** | Представляет вопрос пользователя или ответ AI-ассистента | автор, текст, время создания |
| **Задание обработки (Processing Job)** | Представляет процесс обработки загруженного материала | документ, тип операции, статус, результат |

---

## 4.4. Состояния ключевых сущностей

### Документ

Основной жизненный цикл документа:

```text
Загружен → Обрабатывается → Проиндексирован
                    ↘ Ошибка обработки
```

При повторной обработке:

```text
Проиндексирован → Повторная обработка → Проиндексирован
```

При удалении:

```text
Проиндексирован → Удалён
```

### Задание обработки

```text
Создано → Выполняется → Успешно завершено
                   ↘ Завершено с ошибкой
```

### Диалог

```text
Создан → Активен → Завершён
```
